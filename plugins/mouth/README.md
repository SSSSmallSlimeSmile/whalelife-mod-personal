# mouth · 嘴巴

把一段文字念出来。

三个入口：

- 聊天页每条助手回复右边有个小喇叭，点一下念这条
- 工具 `mouth_say`，别的插件也能调
- 装了 [耳朵](../ear) 的话，按住 F9 说完，回复自动念回来

## 装之前

念声音要一个合成引擎，三种可选：

| 引擎 | 要准备什么 |
|---|---|
| **本地 GPT-SoVITS** | 自己装好 GPT-SoVITS，监听 9880，准备一份参考音频和它的文本。仓库里的 [嗓子](../voice) 插件能帮你启停它 |
| **DeepSeek 云端** | 一把 DeepSeek 的 key，填在插件页上 |
| **宿主登记的 tts 模型** | 在「管理 → 模型」里登记一条类型为「文字转语音」的模型，本插件会自动列进下拉。Key 从那条模型读，插件页不用再填 |

**没有合成引擎就出不了声。** 装了插件但没配上面任何一条，点喇叭只会报错。

## 配置

```json
{
  "enabled": true,
  "engine": "local",
  "url": "http://127.0.0.1:9880",
  "ref_audio": "",
  "prompt_text": "",
  "text_lang": "zh",
  "prompt_lang": "zh",
  "speed": 1.2,
  "max_chars": 110,
  "timeout_ms": 120000,
  "auto_scope": "f9",
  "cloud_key": "",
  "cloud_voice": "tide",
  "cloud_url": "",
  "cloud_path": "/tools/tts",
  "cloud_model": "",
  "cloud_format": "wav",
  "cloud_timeout_ms": 120000
}
```

| 字段 | 说明 |
|---|---|
| `enabled` | 总开关 |
| `engine` | `local` / `deepseek` / `tts:<模型id>` |
| `url` | 本地引擎的地址，默认 `http://127.0.0.1:9880` |
| `ref_audio` / `prompt_text` | 本地引擎的参考音频路径和那段音频对应的文本。**两个都要对**，音色才像 |
| `text_lang` / `prompt_lang` | 合成文本语言 / 参考音频语言 |
| `speed` | 语速倍数 |
| `max_chars` | 单段最多多少字，超了按句切开分段合成 |
| `timeout_ms` | 本地合成超时 |
| `auto_scope` | `f9` = 只有 F9 说进来的才自动念；`all` = 网页打字也自动念 |
| `cloud_key` | 云端引擎自己的 key。**引擎选「宿主登记的 tts 模型」时不需要填**，Key 从那条模型读 |
| `cloud_voice` | 云端音色，DeepSeek 那两个是 `stella` / `tide` |
| `cloud_url` / `cloud_path` | 云端地址和路径，走宿主登记的模型时由那条模型带进来 |
| `cloud_model` | 旧字段，现在由 `engine` 决定，留着兼容 |

## 和耳朵的关系

两个是分开的两个插件，但为一对设计的：

```
F9 说话 → 耳朵识别 → 投进会话 → 拿到回复 → 耳朵调 mouth_say → 嘴巴念
```

**只装嘴巴**：点喇叭能念，网页打字如果 `auto_scope=all` 也会念，但没有 F9。

**只装耳朵**：能听写，回复只在网页上看得见，没人念。

**两个都装**：才是完整的「按住说话、松开听回复」。

耳朵那边有个开关「F9 说完后自动念回复」，就是决定要不要走上面那条链路。

## 念之前会去掉什么

代码块、表格、图片标记、链接、文件路径、行内代码、emoji 图标。长回复按句切段，逐段合成再顺序播，不会一口气念完一大坨。

**表格整块换成「表格略」，只剩代码和表格且实质内容不足 6 个字时不出声。** 念出来残缺不如不念。

## 页面

`/plugins/mouth/`，所有字段都能改，底部有「试听」按钮。

引擎选云端时，本地那几格会自动灰掉，反之亦然。选到宿主登记的 tts 模型时，云端 key 那一格也会灰掉。

## 工具

`mouth_say(text)` —— 把文字念出来。会先做上面那套清洗，再分段合成播放。

## 已知短板

- 云端 DeepSeek 的 TTS **没有音色列表接口**。页面上的「读取云端音色」是用一个非法音色去撞，从报错里抠出合法值，能拿到 `stella` / `tide` 两个，但不是正规做法
- 上一段还没念完又来一条，默认排队最多存 2 条，超过丢最旧的。长回复密集时会丢
- 本地引擎严重依赖 GPT-SoVITS 的参考音频质量。参考音频里有杂音，念出来就有杂音，跟插件无关
- 只在本人 Windows 机器上跑过
