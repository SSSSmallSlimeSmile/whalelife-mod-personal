# ledger · 账本

把会话里记下的每次请求用量，按价目表重算成钱，自己出一个页面。

**只读。** 它不拦请求、不改配置、不写任何东西进会话记录，只是读 `memory/episodes/` 里已有的 `request_usage`。

## 装之前

没有额外依赖。不需要 Python，不需要外部服务，也不碰网络。

前提只有一个：WhaleLife 主干在记 `request_usage`。没记的话页面是空的，不是坏了。

## 配置

```json
{
  "enabled": true,
  "days": 7,
  "max_files": 400,
  "include_judge_usage": false
}
```

| 字段 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 关掉就不注册工具和页面 |
| `days` | `7` | 页面默认看最近几天，页面上也能临时改 |
| `include_judge_usage` | `false` | 要不要额外读 `memory/usage-judge.jsonl`。**没装那个功能的扩展就保持 false**，那个文件不存在，打开只是白读一次 |
| `max_files` | `400` | **目前无效**，代码里没有读它（见「已知短板」） |

## 页面

`/plugins/ledger/`，左侧导航里叫「账本」。

- 每天一张卡片（输入/输出 token、金额）
- 明细表，每一行是一次请求
- 每日输入 token 柱状图
- 模型排名
- 24 小时按模型堆叠图

用量不完整的行（早期记录缺缓存字段）会自动按区间显示，明细表底下会提示「其中 N 行用量不完整」。

## 工具

`ledger_today` —— 不给参数，返回今天到目前为止各模型、各提供方的 token 和金额。口语问「今天花了多少」时会被调用。

## 金额是参考，不是账单

这一点写进页面标题了，也在这里再说一次。

价目表在 `prices.ts` 里手写，按公开报价重算。和真实账单对不上的三个已知原因：

1. **缓存折扣**：有的中转站给，有的不给。记录里没有缓存字段时，按「全部未命中」算上界
2. **折扣**：批量折扣、活动折扣不一定生效
3. **时区**：按 WhaleLife 配置的时区切日，跟账单后台可能差一天

对不上时先看是不是第二种（用量不完整的行被高估），不要先怀疑代码。

## 已知短板

- `max_files` 是死字段，代码里没读它。留着只是占位
- 只认 `memory/episodes/*.jsonl` 这一种来源。别的记录方式它看不见
- 价目表要手动改。上游调价它不会自己跟
- 只在本人 Windows 机器上跑过
